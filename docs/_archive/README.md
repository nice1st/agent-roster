# _archive — 구 세대 초안 (읽기 전용 참고자료)

이 폴더의 문서는 **규범이 아니다.** 살아있는 문서(`docs/*.md`)에서 이곳을 링크하지 않는다.

- `better-auth-superseded-facts.md` — 대체된 설계(api-key 토큰·hd 게이트·도메인→조직 매핑)의 근거였던 Better Auth 실행 검증 사실. 해당 경로 회귀 시 재사용.
- `agora-v0/` — claude-peers 레포 확장을 전제로, 토론방을 중심에 두고 작성된 1세대 설계(00~08).
  현행 계획과 전제 두 가지가 다르다: ① 이 프로젝트는 기존 레포를 계승하지 않는다 ② 중심 단위는 토론방이 아니라 미션·결과물이다.
  기술 검증 내용은 [../02-tech-notes.md](../02-tech-notes.md)로 이식 완료.
