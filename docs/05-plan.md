# 05. 구현 계획

> 무엇을 어떤 순서로 만드는가 — 행 순서가 곧 구현 순서다. 이 표는 계약이 아니라 진행하며 갱신하는 체크리스트다: 셀이 틀린 걸로 판명되면 표를 고친다. 용어·엔티티는 [01](01-domain-model.md).

## 3. 순서의 논리

- **A(1~4)는 저장소 없이 돈다** — 정체성이 레지스트리뿐이므로([01 §3.1](01-domain-model.md)) DB 없이 "두 CC가 브로커 너머로 대화"까지 확인한다. 토큰은 개발용 발급 스크립트로 시작하고 6에서 실키로 교체한다.
- **B(5~7)에서 저장소가 처음 등장한다.** [02 §2](02-tech-notes.md)의 추정(가입 차단 × 계정 연결 상호작용)이 5에서 실행 검증된다. 관리자 부트스트랩은 화면 전에 스크립트로.
- **E(room)가 마지막** — 가장 큰 기능이며, 이 시점에 부품(팬아웃 대상 관리·기록·웹 수신)이 준비되어 있다.

## 4. 확정 결정

셋을 꿰는 논리: 레지스트리가 힙에 있으므로([01 §3.1](01-domain-model.md)) 브로커는 단일 노드다 — 인프라를 거기 정렬하고, 확장 대비는 프로세스가 아니라 모듈 경계로 한다.

- **저장소 = bun:sqlite** — 단일 파일, WAL 모드. Better Auth 테이블은 CLI migrate로, 도메인 테이블은 번호 붙인 SQL 마이그레이션을 부팅 시 적용(이력 테이블로 추적). ORM 없음. 정렬·커서는 rowid([02 §3](02-tech-notes.md)). SQL은 저장소 모듈 안에만 둔다 — 저장소 전환 비용을 모듈 하나로 국한.
- **실행 형태 = 단일 Bun 프로세스** — 브로커·인증·웹 API·정적 UI를 하나의 `Bun.serve`에 경로 prefix로 구획(`/api/auth/*` 마운트 + routes/fetch 폴백 — [02 §2·§3](02-tech-notes.md)). 웹 API가 레지스트리를 직접 읽고 웹 세션을 등재해야 하므로(#10·#11) 프로세스 분리는 프로토콜 비용만 낳는다. §1의 모듈 분할은 코드 경계다.
- **테스트 = bun test 3층** — ① 동작 테스트(주력): 임시 포트로 실서버를 띄워 실제 HTTP/SSE로 검증, DB는 테스트마다 `:memory:`/임시 파일 ② 순수 로직 단위 테스트(교집합 판정·이벤트 파싱 등) ③ 수동 스모크: 실물 CC 연결·Google OAuth 실물 플로우(자동화 제외를 명시). JWT 서명·검증은 테스트 키로 실제 수행한다. keepalive·유휴 타임아웃·room 타이머 등 시간 요소는 설정 주입으로 결정론을 확보한다.
- **연결 위생** — keepalive 주석 프레임 30초(계승값, push 실패 = 엔트리 제거) / 유휴 타임아웃 없음(half-open 좀비는 재시작까지 잔존 — 수용된 트레이드오프) / 프로세스당 연결 수 상한 1,000(초과 register는 503, 리쥼 교체는 통과) / **미전송 큐 상한 없음** — Bun이 소켓 backpressure를 유저스페이스에 전파하지 않아 밀린 양을 측정할 수 없고([02 §3](02-tech-notes.md)), 동기 버스트만 잡는 반쪽 방어는 두지 않는다. 값은 env로 외부 주입, 코드에는 기본값만.
- **room 종료 처리** — 만료의 정확한 강제는 발언 시점 `ends_at` 검사(room-send에서 거부), 만료 스위프는 상태 전환·room-end 통보만 담당하므로 주기 기본 5분(env 주입). 통보가 최대 주기만큼 늦는 것은 수용. 버튼 폭파와 스위프 만료는 같은 폭파 함수를 탄다.
- **웹 UI = React + TypeScript, Bun 내장 번들링(HTML import)** — 실시간(SSE 반영) 화면이라 SPA, Better Auth react 클라이언트 사용. 분리 대비 습관: `web/`은 서버에서 공유 타입만 import, API는 상대경로 + base 상수 1곳. HTML 서빙은 #5에서 스모크 검증, 폴백은 `bun build` 정적 산출물.
- **도구 체인** — Bun 1.3.11 고정(`engines.bun` 단일 소스 + 테스트 프리로드에서 버전 가드. bun은 engines를 강제하지 않음 — 원문 확인). 린트·포맷은 Biome(2 spaces·120). 타입 게이트는 `tsc --noEmit`. JWT는 jose — 브로커 검증은 공개키 주입 구조로, #6에서 키 출처만 Better Auth JWKS로 교체. 의존성은 정확 버전 고정([02 §2](02-tech-notes.md) 교훈).

## 5. 슬라이스 규칙과 남은 결정

- **각 행 시작 때 그 행의 이음새를 먼저 확정한다** — 엔드포인트·페이로드·도구 시그니처. 표는 관여 모듈만 말하고 인터페이스는 말하지 않는다.
- 남은 결정: 없음 — 도구명은 `set_meta`(#9 구현)·`send_room`(#13에서 구현)으로 확정.
